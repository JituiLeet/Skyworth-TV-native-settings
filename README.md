## 安装包说明

### [Settings9.apk](./Settings9.apk)

手机版的原生设置，主界面无法正常打开，只能通过跳转 Activity 来打开某一界面。

### [TvSettings9.apk](./TvSettings9.apk)

电视的原生设置，此安装包没有快捷方式，只能通过跳转 Activity 打开主界面，且仅有英文。

### [signed_TvSettings9_src.apk](./signed_TvSettings9_src.apk)

电视的原生设置，此安装包带有快捷方式，且支持中文。
